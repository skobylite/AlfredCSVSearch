# AlfredCSVSearch
Search CSVs within Alfred

CSV Search Workflow
 

# Usage:
Invoke the file actions with your keyboard shortcut on a CSV file in Finder or Alfred
Select "Search in CSV" from file actions
Type your search query
Press Enter on any result to drill down and search within that row
Press Shift+Enter to copy the matching row to clipboard

 

# Features:
Searches all columns in the CSV
Case-insensitive search
Shows matching results with row numbers
Preview of matching data
Drill-down into individual rows with Enter key
